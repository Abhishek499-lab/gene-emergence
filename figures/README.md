# Manuscript Figures

This directory is intentionally kept separate from the computational
source-data repository during the initial build.

Exactly three final manuscript figures should be uploaded here:

- Figure 1
- Figure 2
- Figure 3

The final rendered figure files should be the exact versions intended
for manuscript submission.

Recommended filenames:

- Figure_1.png
- Figure_2.png
- Figure_3.png

Do not upload historical figure candidates or intermediate forensic
figures.
